# Plan: v0.4.1 fixes from the first real-project rollout

Status: approved by the user on 2026-10-23, in progress. Parent:
[[sluice/plan/master-plan.md]]. Origin: rolling 0.4.0 out to fourteen
worktrees of a real Angular project with husky (never name it).

| # | Finding | Fix | Owner |
|---|---|---|---|
| F1 | A hook line rewritten by `sluice init` (`sluice run --hook pre-commit lint`) fails with "command not found" for a teammate without Sluice, so the rewired hooks cannot be committed for a team | `init` writes a fallback: `if command -v sluice >/dev/null 2>&1; then sluice run --hook <hook> <gate>; else <original command>; fi` in shell hooks (husky, plain, lefthook `run:`); the pre-commit framework gets the same through `sh -c`. Idempotence recognises the 0.4.0 form and the new one; `init --force` upgrades 0.4.0 lines | agent A |
| F2 | `init` rewrites hook files in place (`fs::write`): a hook being executed by `sh` at that moment can read a half-written file | write to a temporary file in the same directory, fsync, keep the mode, rename over the target (the target of an in-repo symlink); same for `.sluice.toml` | agent A |
| F3 | `npm exec playwright test` (used inside package scripts) is not heavy; `npm exec` is a package-manager builtin in the matcher | `npm exec X`, `npm x X` (also with `--` and `-y/--yes`), `pnpm dlx X`, `yarn dlx X` unwrap like `npx X` | agent B |
| F4 | `sluice doctor` warns "no hook calls sluice" on husky v9, because it reads `.husky/_` (husky's runner) instead of `.husky/<hook>` | when `core.hooksPath` is a husky v9 runner directory (`_/h` present), inspect the scripts the runner executes | agent B |
| F5 | A `skip-worktree` or `assume-unchanged` index entry disables the cache entirely; the reason was printed only with `-v`, so a whole afternoon ran uncached unnoticed | `sluice run`, the hook path and `verify` print the reason once without `-v` (`sluice: cache off for this tree: <reason>`); `client.log` records `tree=- reason=<code>`; `sluice doctor` gets a `cache` check that warns and names the entries | agent B |

Every task: tests, KB change note, CHANGELOG `Unreleased`, verification
through Sluice. Release: `scripts/release.sh 0.4.1`, push only after the
user approves.
