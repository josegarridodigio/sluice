# sluice-gate

Sluice: verify each git tree once. A stack-agnostic verification queue and cache for parallel coding agents. This crate builds the `sluice` binary.

Install with `cargo install sluice-gate --locked`, or download a release binary. The full documentation (the problem, quick start, configuration, the MCP server, the merge queue and the roadmap) is in the [project README](https://github.com/josegarridodigio/sluice#readme).

The other `sluice-gate-*` crates are internal components of Sluice with no stability promise outside it.
